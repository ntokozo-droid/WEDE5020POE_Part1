For Part 2 of this project, CSS styling and responsive design principles were applied to the Green Seeds Community Garden website. The goal was to take the semantic HTML structure created in Part 1 and build a visually appealing, user-friendly, and mobile-responsive website.

External Stylesheet: All styles are centralized in css/style.css and linked to all 5 pages (index.html, about.html, services.html, enquiry.html, and contact.html).
CSS Reset: A global reset ({ margin: 0; padding: 0; box-sizing: border-box; }) is used to ensure cross-browser consistency.
Color Palette:
 Primary Green: #2e6f40 (Used for branding, headings, and buttons)
   Hover Green: #1f4d2c (Used for button and link interactive states)
   Background Tint: #f4f7f4 (Light natural background)
   Dark Charcoal: #333333 (High readability text color)
Typography: System font family Arial, sans-serif with hierarchical font sizing (rem) and appropriate line-height (1.6).
Layout Structure: Flexbox (display: flex) is used to align the logo and navigation bar neatly across desktop viewports.
Interactive Elements: Applied :hover, :focus, and :active pseudo-classes to navigation links, form inputs, and buttons.
